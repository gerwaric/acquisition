# Run ledger

Every run of the Rust daemon against the real GGG API, one row each, in
order. The rule a run follows is `LIVE-TESTING.md` (the standing rule
and the rails); the procedure is the live-run skill; the drivers draft a
row (`tools/tracer-rung.sh`, `tools/persist-check.sh`) and a first
contact's row is written by hand. Evidence — journals, daemon logs, run
logs, bodies — is copied to `runs/<date>-<name>/` (gitignored) and cited
by the row, so the row is the committed record of the run. Rows stay as
written: a later fact is a new row or a claim, never an edit to an old
row's evidence.

A row is what the standing rule says: date, daemon tip, result, sends as
POST/HEAD/GET, violations, and notes holding the observed policy, the run
directory and pointers to where each lesson landed — a trap to the
live-run skill, a fact about GGG to a numbered ground-truth claim
(`docs/design/network-ground-truth.md`, authored master-side), an owner
verdict verbatim beside the ruling it decides. The lesson's text does not
live here.
