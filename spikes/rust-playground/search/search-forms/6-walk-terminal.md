- **Paste.** `"+92 to maximum Life"` alone: a phrase; the 92 survives as characters (and `"92 to maximum Life"` would also find 192 — your `Level 1` point). `line("+92 to maximum Life")` and `"+92 to maximum Life">=90`: the two-readings error, both. `"Kaom's Heart"`: a phrase. `sockets` bare: text. **G10** if it matches nothing, v2's zero block promises suggestions for unresolved selectors but does not say a bare word that is also a field name gets "also a field: `has:sockets`".
- **Two cold occurrences, 10–40 and 20–50.** `line("Adds # to # Cold Damage" low>=15 high<=45)`: false, neither member. `"Adds # to # Cold Damage".low>=15 "Adds # to # Cold Damage".high<=45`: true, two members. Adding the second bound from the terminal: the shorthand does not extend, but the answer had already printed `line("…" low>=15)`, so I copied the canonical text and typed inside its parentheses. Printing the group canonically is what made the edit obvious. Evidence for that choice; none either way on multi-slot shorthand, which I never missed.
- **Substitution.** `A or B`, one item satisfying both, `--explain <A>`: as given 1, forced true 1, forced false 1. Literal labels carry it; "contribution" would have lied. `holds(rarity=rare, is:corrupted)=1`, `--alternatives <rarity node>`: the table of file 4's identity. Not worked on the seven items — the scenario does not stipulate corruption — so this probe is unexercised; the identity has only the algebraic check in file 4.

## What I take from it

Calls for step 1, cold: five before the first real answer (accounts, help, language, vocabulary, the query). The vocabulary call is the expensive one and **G2** makes it worse. The gaps that would hurt a real participant most are **G2**, **G6** and **G8**; **G3** is the one most likely to cause a wrong belief rather than a stall. **G5**, **G7** and **G9** are all the same gap seen three times: v2 defines values and never their terminal rendering.
