# The shape of one stats entry

`renderer/public/data/en/stats.ndjson` is one JSON object per line. A line is
either a `Stat` or a `StatGroup` of several `Stat`s that share a displayed
line; the TypeScript is `renderer/src/assets/data/interfaces.ts:3-54`.
`ref` is English in every language file (`renderer/public/data/{en,ru,ko,cmn-Hant}`);
only `matchers[].string` is translated.
